# Eosphorus Labyrinth — Safari Trial

This public distribution repository contains only the standalone static PWA. It does not contain the private development repository, personal vaults, passwords, backups, signing keys or user data.

Open the GitHub Pages website in iPhone Safari and choose Share → Add to Home Screen. Notes are local to each device and can be exported as encrypted backups; browser storage can be erased. The app code and this website are public; account notes are not automatically uploaded.
